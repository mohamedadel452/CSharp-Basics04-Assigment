دليل الغوص العميق: المصفوفات في الذاكرة وتمرير المعاملات (Value vs ref vs out vs params)

شرح معماري لكيفية تخزين المصفوفات في الـ Heap، والفرق الدقيق في الـ Stack Frame عند تمرير المعاملات للدوال.

1. معمارية المصفوفات في الذاكرة: 1D & 2D Rectangular Arrays (Q1 & Q2)

المصفوفات في C# ترث من الفئة System.Array وهي دائماً Reference Types تُخزن في الـ Heap في كتلة ذاكرة متصلة (Contiguous Memory Block):

  • 1D Array (double[] prices): وصول فوري لأي عنصر بتعقيد O(1) عبر المعادلة: BaseAddress + (Index * ElementSize).
  • 2D Rectangular Array (int[,] shelfCopies): مصفوفة ثنائية الأبعاد متصلة في كتلة واحدة في الذاكرة (Row-Major Order)، مما يجعلها صديقة لـ CPU Cache.

2. الفروق الجوهرية في تمرير المعاملات للدوال (Q5 – Q12)

طريقة التمريرماذا يُمرر في الـ Stack Frame؟السلوك عند التعديل داخل الدالة
Value Type by Value (Q5)

Value Type by Reference (Q7)

Reference Type by Ref (Q8)

Out Parameter (Q9)

Optional, Named & params (Q10–Q12)قيم افتراضية وقت الترجمة، ومصفوفة متغيرة الطول مع params.مرونة عالية في استدعاء الدوال بعدد متغير من المعاملات.
